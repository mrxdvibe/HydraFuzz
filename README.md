# HydraFuzz v1.0 🚀

High-performance, multi-threaded directory & URL fuzzing engine built for web reconnaissance and security research.

## Features
- **Multi-threaded Scanning:** Fast directory and file discovery.
- **Custom Wordlists:** Supports standard and custom fuzzing dictionaries.
- **Status Filtering:** Clean output with target HTTP status codes.

## Installation
```bash
git clone https://github.com/mrxdvibe/hydrafuzz.git
cd hydrafuzz
pip install -r requirements.txt
